# 世界有界客户端模型与读取消费者验证

## 目标

验证客户端 USER player/block/entities/scene 为有界客户端世界模型，不依赖屏幕可见性，
不加载区块、不读取服务器/Peer/存档或完整内部对象。UI USER 与既有输入/权限/证据合同保持不变。
同时验证 Provider/State Frame、Deep、Wait/Assert、Event/resync、Recording/Artifact 的
USER/DEBUG 分类、独立授权、异步发布、取消与诚实能力声明。
mode-collaboration专项验证三模式的独立类别读取、TAKEOVER同请求区块字段保留、OPERATE原生命令零输入/保留聊天草稿、接管内typed Debug及模式退出取消玩家队列；包含真实MCP消费者，不模拟物理Esc。
server-completion专项验证显式服务器补全、独立事务/真人future隔离、单飞/预算、草稿焦点保留、实际MCP与退出失效。
这不是命令执行、真人并发Live或零服务器预算影响证明；已提交查询不可撤回，取消后不发布结果。
resource-version专项覆盖六个已批准typed操作的正式inspect、原值/版本条件、safe stale、回读与受控恢复；
本地隔离夹具通过原生暂停稳定动态资源，Arrange输入与零输入DEBUG Act分别计数，未知外部改值/版本不覆盖。
本增量增加 USER 语义目标、原版相对输入瞄准、实际键位 attack/use 短按、持续 mine/use_hold、六面精确 place 与独立效果观察。
新增含水方块、双格植物连锁破坏、副手盾牌持续使用/取消与手冲突拒绝、喂食和原版乘坐/潜行退出。
实体增量通过普通 use 驯服狼、喂食两只成年牛自然产生幼体、拴绳绑定玩家/栅栏及普通攻击绳结释放，
并由村民世界目标打开真实菜单，以既有语义报价/槽位支付与取货。
负面场景包含 READ/OPERATE 拒绝、旧引用、同坐标 A→B→A、遮挡、取消及 held input 清理。

本实例目录发现实际 OS 分配端口，身份握手后固定 runtimeInstanceId；
错误启动身份在输入分发前拒绝，不影响世界 epoch、Storage Identity、Lease 或 scope。
证明本验证列出的方块动作和实体攻击/容器交互，不证明完整世界动作、全部实体行为、命令效果分类、真人撤销、
最终 JAR 安装或完整世界首个里程碑。
UI 与世界联合推进：新增原生细轮廓按钮/拉杆、世界打开工作台后的 3×3 合成，
及世界打开铁砧后的文字编辑、真实取物与重开后物品名确认，不依赖手写屏幕坐标。
新增斧/锹/锄的原版工具作用、错误物品无效果、炼药锅装水/取水，以及熔炉消耗原料、等待烧炼并取出真实成品。
五端均接入真实 MCP stdio 消费者，验证世界 Debug batch 自动以 DEBUG 等待、USER 无法读取结果，
纯 UI batch 自动等待及可恢复的暂停页控件修改，不把两种批次混成同一读取授权。
这些只证明列出的联合业务流程，不替代 UI 固定副本全矩阵、整合包兼容或人工体验验收。

动态菜单场景由原生漏斗持续向木桶槽位 0 输送石头，同时通过语义 hover/click 操作另一个稳定槽位。
并发 USER 树与 input/state 采样必须证明数量更新和指针移动重叠，再独立确认八个泥土实际移入稳定槽位。
变化目标和显式全局菜单版本仍须拒绝，鼠标所持物品与 held input 不留残余；不使用手写 UI 坐标或重放请求。

命令接口使用原生 Chat 绑定、字符与 Enter；增量验证原生命令树效果分类/未确认语义，以及修改命令提交前的录制污染。
无接管和非法多行命令不构成提交；已尝试发送后发生异常的污染由真实 HTTP 回归注入检查，排队取消由共享输入引擎测试覆盖。
Native 与真实 MCP 都核对原生命令树分类及未确认的响应字段；
真实 Chat Screen 输入与 Enter 验证沟通/信息/修改的来源和最终发送前拒绝，松键不抹去已提交回执。
helper 不使用直接发包回退；也不以未决函数/调度拒绝证明完整间接命令解析已交付。
player-command 专项为1.x的11项、26.x的12项：载荷输入前拒绝、原生 Chat/Enter 绕过拒绝、安全 NBT/标量清空的服务器读回，
以及原有模式/聊天草稿/取消/实际 MCP。每个拒绝批次由新 nonce 的服务器 FIFO 屏障确认原生命令数只增加屏障本身，
帮助入口还要求 inputDispatchSequence 不变；原始 Chat 测试有正常文字输入，但不得有服务器命令提交。
探针只在服务器线程计数并读取已加载固定方块的命令摘要，不执行载荷、加载 Chunk 或修改世界；断言来源为 DEBUG。
测试没有证明整套 M-07、其他不透明复制/函数、Peer、最终 JAR 独立安装或人工 UX。
村民交易夹具逐条通过原版命令构造，全部符合原生聊天长度，测试仍须实际支付和取得商品。
修改命令的 USER Artifact 必须保留诊断 authority、原生输入来源和效果未确认字段；
校验器要求恰好一个尝试与提交事件，不再把 PLAYTEST 当作所有命令污染的固定 authority。
共享 HTTP/WebSocket 回归另外核对终态事件的状态及部分来源，事件不能先于 Operation 状态提交；
终态回调不持有 Operation monitor 等待控制锁，不把清理中的来源记录伪称完整。
各 Target 的 Brigadier 回归核对参数读取越过 EOF 时仍遵循原生 execute 的结束判定；
Forge 另外使用真实 ComponentArgument 覆盖有效 JSON、损坏 JSON 与未解析尾随文本，不执行任何游戏命令。
