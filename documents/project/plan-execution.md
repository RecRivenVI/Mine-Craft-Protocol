# Mine-Craft-Protocol 当前执行计划

当前授权为命名、扩展包原生配置界面、接管提示预览与远程CI；基线develop/ac12a43a，既有固定Alpha保持不变。1.0是内部质量标准，不表示公开发布。

## 目标

统一产品与SDK命名，提供遵循原版资源包体验的扩展包管理，在保留模式、权限、Lease、Human Override及证据隔离合同的前提下完善提示框；远端按模板规则恢复可执行CI。

## 范围

- 五个已登记Target；不改Minecraft/Loader版本或本体Java根包。产品显示名Mine Craft Protocol、mod_id mine_craft_protocol、版本1.0.0-alpha。
- 术语extension/extensions/extensionpack；独立包ID采用目标mod_id，代码统一到minecraftprotocol.extensions；SDK采用api和api.extension，验证源码集与验证模组保留probe。
- 扩展包界面复用原版资源包风格，不允许重排序；固定内容身份批准，初次批准只接受物理输入，Agent只能操作已批准包的开关及完成；修改重启生效。
- 按内容哈希/权限和依赖状态控制早期装载；普通客户端配置入口与Fabric可选Mod Menu；服务器不加载客户端页面。
- 提示框只先做可撤回游戏预览，细物理像素边框、圆角与轻高光，不改外圈呼吸、图标和标题后缀；用户确认才实装。
- Companion网页仅为体验标准接口的测试页，不承担扩展管理或交付业务。
- 不做整合包、E1～E3、Persistent Write、性能基准、Fake Player、第二界面或其他新功能。不重写历史证据或旧Alpha。
