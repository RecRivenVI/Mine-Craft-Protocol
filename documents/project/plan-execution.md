# Mine-Craft-Protocol 当前执行计划

当前计划已按2026-10-18用户批准的协作控制目标重定基线：分别交付 UI 与世界首个里程碑，并准备对应 Showcase。
新目标不是已有实现的验收结论；两领域尚未 READY，READY 也不等于人工 PASS。
已恢复首批共享准入、独立工作生命周期及 OPERATE 原生命令实现/自动验证；不自动启动人工验收。
按用户要求，自动 Goal 保持暂停且本轮不修改其正文/状态，等待外部评审恢复；开发按本计划有界推进，不能直接续跑旧 Goal 范围。
恢复工作先读[唯一当前状态页](status-milestones.md)：工作包×五 Target、剩余验收组、估算与下三步只在该页维护。

## 目标

以 Core 的 Agent-native Minecraft Autonomous Testing Platform 为交付边界，
让 Agent 经正式 Native/MCP/网页接口观察用户、合作测试/游玩，或在明确授权后代替用户操作。
USER/DEBUG 表示操作和数据的来源，不再用模式互斥阻断合法回读；READ 只读，OPERATE 不接管真人输入，TAKEOVER 才接管。
两领域均覆盖仅客户端、仅服务端和双端联动的适用能力，完成五端正式制品、真实消费者、取消清理与证据验收。

## 范围

- 按[Core](scope-core.md)、[控制模型](../design/concept-agent_control.md)、[世界目录](../design/concept-world_control.md)
  和[原版UI目录](../development/testing-vanilla_ui.md)执行 M-01～M-12；WU-01～WU-20、WD-01～WD-12 是有限家族，不扩成所有参数、物品或种子的笛卡尔积。
- UI USER 仍限该主体实际呈现；世界 USER 仍为有界客户端缓存，不自动加载区块或开放服务器内部数据。
  所有模式均可进行独立授权的两类读取；DEBUG 修改可在 OPERATE/TAKEOVER 执行，仍需自身 scope/Arm/前置条件。
  依赖共享键鼠/焦点的输入只在 TAKEOVER + 既有 Lease 下执行；OPERATE 可执行获准的非接管原生操作，USER 失败不得静默回退 DEBUG。
- 真人 Esc 仅撤销 TAKEOVER 及其 active/queued 输入，held input=0、无迟到输入，保留观察与独立合法 DEBUG 工作。
  持续通知用户手动结束接管及重新同意要求，由模型决定是否继续 DEBUG 或非接管命令；不伪造 Runtime 聊天同意验证。
  OPERATE 与真人可并行并覆盖用户操作，但不绕过 owner thread、实际授权或显式资源/值条件。
- 所有命令操作统一 USER，不按作弊权限逐条划成 DEBUG；命令树只提供当前主体可用性线索，不等于权限授予或执行成功。实际修改及证据来源另记，USER不等于纯gameplay。
  首先实现 OPERATE 下真实玩家原生命令提交：不打开聊天框、不改草稿/焦点、不模拟 Enter，不取得 Lease、不自动切 TAKEOVER、不提升 console 身份。
  当前聊天输入路径仍需 TAKEOVER，不能仅删除其门禁。其他原生玩家动作按共享输入/上下文及原生校验依赖逐项评估，不自动全部开放。
  补齐可用命令发现、有界批量/逐项反馈、读取到写前版本的闭环及动作后回读；不承诺服务器原生不存在的请求关联、原子事务或自动重试。
- M-09 将[三部署](../design/concept-deployment_scenarios.md)完整纳入本次双里程碑计划：单端安装表达、独立零玩家服务器 Runtime、
  非图形控制台、接收端授权及双端资源路由。当前 mod_side=both 和有限 Peer 不证明这些已实现；先解决符合模板的产物与安装方案。
  控制台输出/补全/原生命令输入属于 UI 表面，世界效果归世界；无玩家不伪造玩家 USER 视角、HUD 或截图。
- 对 Structure/Test 等不透明管理效果、函数/调度、来源不明复制，发送前拒绝、零相关服务器副作用和明确限制即可关闭对应必需分支；
  不能将未接守卫或未实测的拒绝写成通过，也不能将原生先保存造成的部分提交说成零修改。
- 首次 Developer Preview 只交付 Core；[E1/E2/E3](scope-extensions.md)可延期或取消，不阻塞 Preview。
  Persistent Write、安全基础后的正式写入审查、Phase 9E/9F/9G/10、整合包测试、寻路及 Render Forensics 不在本目标内。
- 独立 Agent 玩家体系另设自身 READ/OPERATE/TAKEOVER，和真人客户端体系不共用模式开关或玩家身份；Fake Player、第二游玩界面目前只做独立可行性研究。
  研究未决能力不加入本次必交付实现，不借此自动启动 E2。
- 保留用户工作树，未经明确授权不暂存、不提交、不推送、不建 tag。只操作本线程隔离实例，默认一次一个客户端、4 GiB 最大堆；禁止 Computer Use、宿主输入模拟及外部 Prism/重要存档操作。

## 步骤

已有分类隔离、原版 UI/世界语义操作、typed Debug、固定副本与展示脚本作为实现基础复用；旧证据不证明新合同。
执行顺序按依赖推进，不按每次调用切模式，也不逐个深化未知程序。具体分组与数量只在状态页维护。

1. 完成：按当前用户决定重写双里程碑目标、模式/类别、人工退出、三部署与研究边界；本项完成只表示规划对齐。
2. 进行中：M-01，共享读取/修改准入及独立工作生命周期已接入；同步 Native/OpenAPI/MCP/网页、条件/Provider/异步消费者，继续补完整合作并发与模式/权限诊断。
3. 进行中：M-07，OPERATE原生命令、本地/显式服务器补全与有界批次已接入；六类世界正式inspect版本链及UI进度画布二维平移已完成五端专项与同候选整体交付复验。后续收口完整真人协作、权限变化及独立回读，不以邻近聊天猜成功。
4. 待办且存在决策阻塞：M-09，当前模板唯一mod_side不能表达可选单端/双端安装；保留both合同，等待合规产物方案后再接独立服务器认证/发现、控制台与Peer授权。不得将可选通道或开发启动等同正式制品支持，也不据此扩大当前产品身份。
5. 进行中：M-02/M-03/M-04，复用现有 UI USER、typed DEBUG 与 HUD/Toast 基础，按有限原版目录补剩余家族；加入控制台适用表面与消费者，不以无法操作未知高风险回调无限阻塞。
6. 进行中：M-05/M-06，复用有界客户端模型及 WU/WD 目录，补齐语义玩家动作、typed DEBUG 和部署适用范围；不新增寻路、任意对象写入或服务器全知 USER。
7. 待办：M-08/M-10，扩展固定副本和主体配置，覆盖五 Target × 三部署、缺权/撤权、合作并发、Esc/Lease/断线/停服与同候选最终 JAR 安装；不把静态检查写成运行 PASS。
8. 待办：M-11，保留已验证展示集合，追加真人游玩时OPERATE原生命令、接管内DEBUG回读、USER命令/批次及三部署展示，逐例提供Arrange/Act/Assert/Evidence和恢复说明。
9. 待办：M-12，审计目录与限制，生成同候选五端 alpha、清单和 Agent 手册并发布不可变快照；两领域与 Showcase 均 READY 后再交用户验收，随后停止。

每个增量先在参考端及受影响 Target 执行相关回归；每三个增量、共享代码变化或候选冻结时跑五端完整矩阵并刷新 alpha/手册。
当前收口顺序、各包带编号的剩余验收组和粗估工时只在状态页维护；优先把最接近完成的包推到V，
每关闭一包立即更新该页，不以反复深化单一管理型边界代替广度完成，也不将V冒充READY。
刷新验证成功后按[固定分发工作流](../development/workflow-alpha_agent.md#固定分发与使用登记)发布同批七文件快照，再更新latest.txt；
其他线程只复制固定快照，不引用build/。保留最近三份和登记在用的批次，不覆盖已发布内容；这不扩大里程碑范围。
同一失败无实质改动最多重试三次；有界定位原因，不降低断言、不吞错误、不拼接不同候选结果。
游戏运行与 Gradle 构建串行，运行有 deadline；只关闭确认属于本线程的进程。当前权限合同不足以决策时保留原合同，提出最小决定点。

## 并行实施

主线程负责共享授权/生命周期、Native/OpenAPI/Companion接线、统一构建与运行验收；
三个实施子代理分别负责UI、世界、命令/部署，另由只读子代理审查权限和并发边界。
子代理继承主线程相同模型与思考等级；共享热点只有主线程修改，各线按明确文件所有权交付。
参考端先实测再移植；测试期间冻结该候选的产品和工具源码，不将不同候选的PASS拼接。
游戏启动、Gradle、格式化和最终分发由主线程串行执行；不恢复暂停的Goal，不新增提交或推送。

M-09的单端/双端产物表达仍有阻塞：当前模板的唯一mod_side事实只接受both/client/server，
其中both明确要求双端安装，不能把可选网络通道等同正式三部署支持。
在确认合规产物方案前保留现有both合同，不擅自修改模板、模组身份或对外声明；其他工作包继续推进。
