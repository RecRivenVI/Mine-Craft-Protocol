# 更新日志

适用于 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge 与 26.3 NeoForge/Fabric。

## [未发布]

### 新增

- 独立服务器增加无在线玩家的主世界诊断读取和已加载方块强类型修改；复用独立权限、Arm、资源版本及有界批次，不经控制台命令、不接管玩家，保留前后状态与诊断证据。

- 独立服务器增加零玩家 Runtime、独立实例发现与控制台授权；可读取有界实时日志并在操控模式提交有限原生命令，不接管管理员终端、不使用玩家租约，不把分发回执当作世界效果确认。

- 世界实体读取纳入原生客户端部位列表，以部位名及独立目标引用支持真实多部件交互；保留原版遮挡，父实体死亡后旧引用失效，不以父实体替代实际命中部位。

- 实体语义交互支持有界的原生部位选择，保留原版输入、命中与租约；展示框读取补充客户端显示物及旋转，不开放隐藏库存。

- 普通语义方块使用可选择有界的原生表面位置，支持区分书架等小格；保留新鲜目标、原版命中、输入租约与独立效果观察，不扩展为屏幕坐标或直接容器修改。

- 自身乘坐反馈补充本地载具类型与原生控制者判断，区分乘客和驾驶；不返回内部关系身份或授予输入权限。

- 自身玩家读取补充原生姿态、游泳/滑翔、流体/着火/睡眠/死亡反馈、视角、空气上限与经验；不开放服务器权限或内部物品数据，仍需独立观察动作效果。

- 独立调试授权下支持玩家和已加载实体的原生精确位置/朝向及跨维度转移；检查源/目的已加载边界、关系与资源版本，实体重建失效旧身份，玩家换维度要求显式重新授权，不接管键鼠或写入持久化存储。

- 独立调试授权下支持已加载实体的原生骑乘、牵引和驯服归属修改，校验受影响参与者的关系版本，保留原版容量、冷却和连带副作用；当前玩家骑乘需玩家与实体两类授权，不接管键鼠。

- 独立调试授权下支持原生时间、天气计时器和可用游戏规则的强类型修改与恢复；控制编辑版本不随自然计时失效，不占玩家输入，也不提供模拟暂停或存档写入。

- 独立调试授权下支持已加载区域的原生实体工厂创建和明确身份移除；创建前检查完整有界成员版本，删除不可恢复，不自动加载区块或接管玩家输入。

- 独立调试授权下支持玩家食物、空气、经验、逻辑速度及已加载实体生命/标志的强类型设值，保留原值/版本检查与真实原生回读，不接管玩家键鼠。

- 独立调试授权下支持玩家原生库存、六个装备位置与已加载容器的强类型物品替换，检查版本、原值及原生堆叠/耐久范围，不占玩家输入。

- 调试读取支持密集方块实体的有界续页；保留独立授权、已加载范围及序列化预算，明确每页实时而非跨页原子快照。

- 系统、教学、进度与配方通知读取提供原生进出阶段、裁切边界和不透明实例标识；保留完全显示时的文字阶段，不公开部分遮挡或尚未绘制的全文。

- 客户端世界支持有界方块小节分页、短期续读与取消；只读取已加载缓存，明确未加载、时效和非原子跨页语义。

- 事件连接可显式订阅自身客户端每tick位姿与速度，独立读取授权且不占玩家输入；旧世界的排队帧、重放与条件证据失效时要求重新同步。

- 同一接管租约可显式强停止当前、排队及已接受但仍在预检的玩家输入，并释放按住的按键和鼠标；不退出接管、不撤销租约、独立调试或人工撤销提示。停止响应超时不撤回必需清理。

- 输入读取提供清理代次、进行中及失败状态；独立等待条件只检查实际自有按键和鼠标都已释放，保留读取授权，不把瞬间松键视作队列永久空闲。

- 输入清理绑定真实世界、玩家与连接代次，换世界取消旧active/queued输入，不把旧鼠标松开事件派发到替换后的界面；普通界面切换保留既有语义。

- 输入管线提供内部队列、回调入口、步骤和清理的单调计时，明确不等同网络耗时或服务器效果确认；保留原有GUI观看节奏和取消合同。

- 界面读取区分交互与HUD/通知呈现计数，槽位说明实际原生容器归属；USER掉落物读取提供客户端同步的物品种类和数量，不包含NBT或组件数据。

- 命令接口支持当前玩家原生命令树、本地或显式服务器补全，以及最多32条的非接管串行命令批次；服务器补全使用独立请求并优先真人待完成补全，预算仍共享，逐项提交不冒充执行成功或事务。

- 界面诊断可按实际原生范围平移当前进度画布，固定轴保留原生居中；不产生玩家输入或解锁进度，旧界面和版本条件仍拒绝。

- 界面诊断节点说明实际原生目标支持的强类型修改、值单位与副作用；普通用户读取不包含这些调试信息。26.3支持本地好友通知的单向隐藏，不联系账号服务。

- 正式深读资源版本可直接用于批准的世界调试修改；完整授权后的旧版本错误提供安全计数和重新读取提示，不授予权限或自动重试。

- 不接管模式可按独立命令授权使用当前玩家原生命令路径，保留服务器权限，不占输入租约或改动聊天草稿；真实聊天输入路径继续要求接管。

- 界面诊断支持驻留系统通知的显式双字段文字重置、教学提示显示进度及原生单向隐藏；保留独立授权、内容/生命周期版本与零玩家输入，不冒充教学完成或富文本/计时回滚。1.20.1系统通知没有原生强制隐藏入口，明确拒绝该分支。

- 界面调试支持本地标题、副标题和动作栏的有界纯文字替换；复用独立UI授权与完整内容版本，不模拟玩家或修改世界，明确原生命期/格式的恢复限制。

- 界面调试滚动支持创造物品栏、织布机、切石机及交易界面的原生本地卷轴；使用归一化位置和既有独立授权/版本条件，不模拟玩家输入或执行交易。

- UI调试文本支持原生多行编辑器、可编辑书本与告示牌草稿；保留原生限制、独立授权、完整文本版本与零玩家输入；原生草稿可能随关闭提交，文字恢复不等于隐藏格式或服务器事务回滚。

- 限流错误提供实际限制桶的额度、剩余额度和建议等待时间，Native、Companion和网页保留结构，不自动重放输入。

- 原生聊天命令增加500ms内的有界客户端反馈，明确仅按时间关联、不保证执行结果；不改变玩家权限、命令分类和证据污染。

- 页面条件支持显式组合就绪等待，保留区块读取的未知、未加载与空气差别；客户端玩家读取补充游戏模式、着地和正在飞行，未知不伪造默认值。

- 目标未命中时提供有界的实际客户端命中诊断，保留原版射线、遮挡与输入拒绝规则。

- 26.x的非命令服务器自定义点击动作在原生最终发送边界明确拒绝；不信任命名空间、不解释未知载荷，普通命令链接仍走现有玩家命令门禁。

- UI读取新增原生生命、护甲、食物、氧气和坐骑图标的有界绘制顺序及样本状态；只读且不透露比图标更精确的内部数值，不自动获取玩家控制权。

- 方块强类型调试修改支持原生合法属性及属性值前置条件，同类型更新保留未指定属性；未知属性、非法值、旧版本与授权不符在修改前拒绝，诊断证据与正常玩法仍分离。

- 自动合成器网格的可见禁用状态进入语义槽位读取；仍通过原版点击切换，状态变化推进菜单版本并使移动中的旧目标失效。不新增调试修改或绕过接管权限。

- Jigsaw 最终方块配置接入原生管理提交守卫，区分命令与方块状态载荷；未决模板生成拒绝，失败仍保留之前已提交配置的诊断来源。Native、MCP 和 Artifact 同步类型信息，不伪造回滚或生成成功。

- 玩家命令载荷的有界原生检查覆盖命令字段、Jigsaw 最终方块及物品数据；嵌入宿主管理或未决命令会拒绝，不隐式读取服务器来源数据。普通聊天输入和辅助入口共用守卫，原有权限和证据分级不变。

- 命令方块与命令方块矿车的界面配置经过最终命令包守卫；复用独立命令权限与接管许可，拒绝宿主管理或未决效果。配置和清空均保留诊断污染，Operation、MCP 与录制来源不冒充命令执行成功。

- 玩家命令通过原生聊天键、字符输入和 Enter 提交，尊重游戏输入上限和已有草稿；取消后不会继续输入或偷偷提交。状态修改仍属于诊断证据，提交不代表效果成功。

- UI 与世界联合验收增加斧、锹、锄和炼药锅桶交互，以及熔炉真实烧炼与语义槽位取物；复用普通使用和界面输入，不新增工具 ID 执行分支。

- UI 与世界联合验收加入工作台 3×3 合成、铁砧真实命名取出和重开确认；全部通过语义目标及正常玩家输入，不调用菜单业务函数。

- 世界普通实体读取增加客户端幼体、适用动物驯服/坐姿及牵引反馈；不公开主人身份、繁殖冷却或服务器内部状态。

- 实体交互验收增加普通输入驯服、繁殖、拴绳/栅栏与实际村民支付取货场景，复用现有接管和语义菜单接口。

- 世界持续挖掘识别含水替代与原版同步连锁变化；副手持续使用保持原版选手与空主手前提。玩家普通读取增加实际使用手与乘坐状态，喂食和骑乘效果保持独立观察。

- 世界接管增加有界持续挖掘、蓄力使用和指定方块面/面内落点放置；执行中复验目标，取消释放输入但不回滚原版松键效果。客户端使用状态与生物受伤动画可用于独立观察，不作为服务器效果保证。

- 世界 USER 有界客户端模型提供短期语义目标；接管时可通过真实玩家输入瞄准并短按攻击/使用。操作前复验目标生命周期、物品、距离与原版命中，不自动走近或绕过遮挡；实际效果另行观察确认。

- 五个 Target 的 Runtime 自动端口及按实例发现；重复实例目录拒绝，连接固定到本次启动身份，避免端口复用后串连。Companion 与验证编排使用同一实例合同，显式固定端口仍支持，不改变权限、接管或证据规则。

- 世界读取的 USER/DEBUG 类别扩展到 Provider/State Frame、Deep、Wait/Assert、事件和录制/Artifact；内部数据需要明确的诊断授权，不能通过普通断言、计数或旧录制重取。Native/MCP 对齐，不自动切模式、授予权限或改变证据分级。

- 普通世界场景的原版瞄准轮廓只读呈现；保持有界、短时、原生来源，不公开内部坐标/材料身份，不冒充完整实体/地形感知或语义世界操作。

- 旁观者菜单的语义打开、选中和明确执行；重复点击不隐式传送，未选中项内部名称不混入普通读取，网页沿同一接管输入路径操作。

- 创造物品栏、织布机、切石机与交易界面的语义滚动轨道和滑块；按原版实际可拖动区域定位，保留禁用状态及滚动后旧目标拒绝，不直接修改滚动位置。

- 已保存服务器列表的连接和上下排序语义子节点；遵循悬停显隐，排序后拒绝旧目标，扫描提示不再冒充可点击行。

- 玩家列表文字读取遵循原版展开状态、显示名与列表筛选，不将隐藏列表、账号内部数据或精确延迟混入普通读取。

- UI 专用调试操作：控件启用/显隐、原生文本框、列表滚动与滑块设值，复用独立授权、版本前置条件和诊断证据；不模拟玩家。滑块使用原生设置回调，可能保存选项。

- 有界 HUD 标题/副标题/动作栏与 System/Tutorial/Advancement/Recipe Toast 读取，用户视图不包含隐藏或排队消息。

- UI 读取补充热栏/副手、Boss 栏、侧边计分板与状态效果图标；区分隐藏 HUD 与普通可见内容，遵循原版排序、裁剪和数字格式，不泄露效果等级/时长。

- 通用原版交互区域：滚动条拖动、书本/聊天富文本链接、聊天建议选择与进度画布，保持原生输入和安全边界。

- UI 树区分当前菜单的鼠标所持物品与槽内物品，并提供实际弹层遮挡状态；不混用客户端、服务器或磁盘权威。

- 原版资源包选择/排序、特殊菜单选项、书本多行编辑/签名/翻页和普通/悬挂告示牌行编辑的语义节点；保持真实游戏输入，不使用截图或手写坐标。

- 原版 UI 容器/列表递归语义节点、文字输入、滑块比例设置、滚动到隐藏目标和创造标签/配方书控件；保持接管、安全与截图隔离。自绘未知区域仍明确受限。

- 本机网页界面工作台：按标准接口显示控件位置、大小、文字和背包语义槽位，明确申请接管后可点击、悬停、右键及 Shift 点击并同步游戏变化；可按需获取实时截图作为底图，不修改 Runtime 或绕过权限。

### 变更

- 更新现有Minecraft版本对应的稳定NeoForge、Fabric API、Loom与Companion校验库；游戏版本、最低Loader要求及权限合同保持不变。
- 三模式均按独立权限读取 USER/DEBUG；接管内允许独立授权的 typed Debug/Fixture。人工退出只撤销接管输入，不中断活动任务、读取或独立调试，重新同意提示仍持续有效。
- 世界普通读取改为有界客户端世界模型：支持玩家状态、附近缓存方块与追踪实体，不依赖画面可见性；明确范围/截断，不加载区块、不读取服务器或存档。UI 普通读取、玩家操作、权限和证据合同不变。
- 模板规范升级到 2.0.2，构建插件与规范附件统一由 gradle/conventions 提供；更新固定版本 Forge/NeoForge 与 26.3 NeoForge Loader，保留最低加载器要求和既有产品合同。
- 窗口标题和图标统一加工游戏提交到原生窗口的最终输出；标题文案不变，接管图标改为原图右下四分之一叠加最近邻缩放的像素圆球，各尺寸分别合成、退出恢复最新原图。游戏内 Pointer 尺寸、输入与证据隔离不变。
- UI 读取开始区分 USER 与 DEBUG：默认只提供可见内容，内部 UI 图需要独立读取权限；
  玩家式 UI 输入仅使用 USER 路径，UI 首个里程碑仍在实施中。
- 本机网页简化为游戏窗口与截图管理，支持直接点击、拖拽、滚轮、键盘和最终 IME 文字；不会自动接管或控制第一人称视角。
- 发光圆球采用解析弹簧移动与 70% 点击缩放；Control Chrome 默认蓝色为 #339CFF，加入 500 ms 提示过渡、440 ms 指针显隐和 3 秒蓝边呼吸。输入落点、安全与截图隔离保持不变。
- GUI 虚拟指针改为蓝色发光圆球，加入确定性轻微回弹与可取消的界面观看节奏；保持真人 Esc、输入释放及截图/录制隔离。
- 圆球采用 24×24 偶数像素尺寸并扩大明亮本体，真实点击提供缩小/恢复反馈；不改变点击坐标与输入时序。
- 统一仓库构建、组件、实例配置和验证工具位置；保持既有产品功能与协议。
- 滚动 Minecraft Target 升级到 26.3 正式版；固定 Minecraft Target 更新 Loader，构建、测试与 Companion 依赖同步升级。
- 适配 26.3 SDL 输入/窗口及 Renderpearl 呈现接口，保持既有控制、宿主光标隔离与录制证据合同。

### 修复

- 纯语义瞄准使用有界的原生客户端射线，可看向交互距离之外的已知目标；近身攻击、使用、放置和挖掘不扩展原版作用距离。
- 玩家死亡时立即清理旧的按住状态并取消活动/排队输入；死亡界面仍可使用既有接管租约操作重生，不误报为人工撤销。
- 语义世界动作以当前视点和原版命中持续复验，不再将正常玩家移动误判为身份变化而取消；保留世界、目标、物品、窗口与输入租约检查，不自动寻路或改动玩家坐标。
