# 使用核心自动测试能力

适用于 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.3 NeoForge 与 26.3 Fabric。
你可以让 Agent 观察游戏、接管玩家操作、执行条件测试并保存证据；正式持久化写入尚未提供。

## 安装与连接

1. 安装与你的 Minecraft 和加载器匹配的最终产品 JAR，不同时安装旧版或单独安全库。
2. 对 Fabric 安装同版本的 Fabric API。
3. 启动安全测试实例，通过本机 Runtime HTTP/WebSocket 或 MCP Companion 连接。
4. 使用实例生成的认证令牌，按需要授权 scope，不将令牌发到公共聊天或提交。

## 控制与安全

- READ 只观察；OPERATE 的 Fixture/Debug 仍需各自授权；TAKEOVER 才能代替玩家输入。
- 真人按 Esc 立即结束 TAKEOVER，观察继续可用；重新接管前 Agent 必须再次得到你的明确同意。
- 接管中的宿主光标保持自由，GUI 使用游戏内部虚拟指针。
- 虚拟指针为 #339CFF 蓝色发光圆球，移动使用弹簧自然回弹；点击前停稳，按下时缩至 70%、松开后恢复，拖拽不做越过。
- 顶部提示平滑淡入淡出，四周蓝边轻缓呼吸；只有视觉渐变，权限生效与退出接管不会等待动画。
- 窗口标题保留游戏原文并附加当前 Agent 状态；接管时，原窗口图标的右下四分之一叠加蓝色像素圆球角标。结束接管恢复游戏图标，游戏自行更新标题或图标时也会保留其最新内容。
- 球心对应实际操作落点，保留小数位置，不因画面缩放取整偏移；窗口右侧、底部的有效小数位置也不会因换页或缩放截断。背包格子按原生点击区域居中，悬停、点击与拖拽使用一致坐标。
- 创造背包的每个格子也有唯一语义编号，Agent 可直接选择格子进行悬停、点击和拖拽，不必使用坐标绕过。
- 普通菜单换页保留圆球位置；从第一人称打开背包等游戏有效释放动作遵循原版归中与显示规则，关闭时隐藏。宿主鼠标移动不会覆盖虚拟光标。
- 界面打开和连续操作之间保留短暂观看时间，减少高速切换造成的闪烁；这不会延迟 Esc 撤销或输入释放。
- 控制边框、提示与虚拟指针只供你观看，不进入默认截图或录制画面。
- Debug/Fixture 证据不等同正常 gameplay；旧验收记录不代表当前版本已通过你的画面验收。

## 原版界面操作

Agent 可以直接选择世界列表中的存档、填写文本、调整滑块、滚动隐藏条目，
并操作嵌套按钮、创造物品栏标签和配方书控件；实际鼠标与文字输入仍经过游戏的正常输入路径。
界面或目标在操作途中改变时会拒绝旧目标，不会改为点击旧坐标。
连续浏览多个页面时，身份缓存回收不会整批作废当前控件；长期未使用的旧目标仍需重新读取。
可按语义选择/排序资源包，操作交易、附魔、织布机、切石机与信标，编辑书本及普通/悬挂告示牌。
多人游戏列表中的已保存服务器也可按语义选择；悬停后读取连接和上下排序图标，添加、编辑、删除仍走原版界面与确认。
可以读取并操作书本/聊天文字链接、聊天建议、列表滚动条和进度画布；进度节点只提供实际存在的悬停能力。
创造物品栏、织布机、切石机和交易界面的滚动轨道与滑块也可按语义拖动；
没有足够条目时保持原版禁用状态，滚动后重新读取可见槽位、图案、配方或交易再操作。
文字链接保留原版确认流程，不自动执行内容。网页支持直接 GUI 输入与截图观看，不提供第一人称操作。
不需要截图不等于所有原版界面都已验收；账号服务、外部文件选择与第三方自绘内容仍有明确边界。

在单独授权的调试操控中，Agent 可以修改已支持控件的启用/显示状态、文本框内容、列表滚动位置与滑块设置。
调试滑块也会触发游戏本身的设置回调，可能保存选项；测试结束后需显式恢复，不是无副作用的预览。
这些不是玩家操作，不能计为正常游玩证据；界面或状态变化后必须重新读取，旧条件会被拒绝。
普通读取另可提供标题、副标题、动作栏、热栏与副手物品、Boss 血条、侧边计分板、状态效果图标、已展开玩家列表的文字及部分提示消息。
玩家列表只读取实际显示名，不额外公开被显示名替代的账号名称、UUID 或精确延迟；列表关闭时不作为可见内容返回。
效果图标读取原版实际绘制的显隐与透明度，包括即将结束时的闪烁；透明或缺少有效渲染样本时不作为普通可见数据返回。
不泄露未显示的等级或持续时间；第三方替换效果图标的绘制暂不保证适配。
隐藏界面中的信息不会当作你已看到的内容；计分板隐藏的分数和物品内部属性也不会混入普通读取。
这些显示内容不是可以点击的控件，尚未覆盖全部 HUD。
旁观者菜单可通过中键打开并按语义选择图标；选中与执行分开，重复点击不会意外传送。
网页中单击选中，双击已选中项或 Enter 明确执行；关闭和超时仍由游戏正常处理。
菜单隐藏时不提供普通可见节点；鼠标或带加载器修饰键的热栏绑定暂不支持，不会猜默认键位。
配方解锁提示和多行进度提示也可读取；进度先显示标题、再显示名称时，普通读取跟随当前阶段，
不提前公开尚未显示的文字。提示正在滑入、渲染样本过期或画面尺寸刚改变时，可能暂时没有普通读取结果。

## 更多说明

世界领域开始区分普通读取与内部诊断。普通玩家读取暂只提供已有可见热栏、副手和效果图标，
不会额外给出精确坐标、生命或实体内部身份；普通场景感知尚未完成，会明确说明不支持。
精确内部查询需要显式选择诊断类别、独立授权及合适模式，不会因为接管而自动获得。
其他世界读取与录制等尚未全部分类，当前内部试用版不能当作完整的玩家信息隔离或世界覆盖交付。

开发、构建与当前验收状态见首页与文档导航；你可以先用 Showcase 逐个观察控制 UI，再决定视觉调整。
