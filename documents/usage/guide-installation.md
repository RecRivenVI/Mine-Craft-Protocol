# 使用核心自动测试能力

适用于 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.3 NeoForge 与 26.3 Fabric。
你可以让 Agent 观察游戏、接管玩家操作、执行条件测试并保存证据；正式持久化写入尚未提供。

当前开发者预览提供不依赖玩家在线的控制台入口。服务器所有者可单独授权 Agent 读取实时日志、
提交有限的原生命令；它不会接管管理员终端，也没有玩家画面或键鼠接管能力。
默认不开放控制台权限，仍需所有者明确配置；当前仅支持帮助、玩家列表、服务器发言、种子、时间和天气等命令根。
停服、权限管理、保存/重载等管理命令尚未开放，管理员仍可使用原生控制台；这不是完整服务器管理工具。
命令已分发不保证效果已达成，也不等于普通玩家测试通过。两端安装均为可选，功能按实际安装位置及授权提供。

界面读取区分可交互控件图与HUD/通知呈现图，并标明可见槽位属于玩家背包还是当前菜单；加载覆盖层后的底层标题不会被当作当前可见标题。
附近掉落物可以返回客户端已知的物品种类与堆叠数量，不读取额外物品数据或服务器内部状态。

调试授权下可以分页读取已加载的密集容器等方块实体；续页不会加载新区块，动态世界的多页结果不保证属于同一时刻。
独立调试授权还可替换背包、装备与容器物品，设置有限的名称和耐久数据；未开奖励容器须先经普通玩法打开，不会暗中生成战利品。
玩家最大生命值等原生属性也可在合法范围内调试修改；各版本使用对应的原版属性，兼容请求不绕过授权、当前资源状态或原值检查。

读取或输入触发限流时，Agent可以获取实际额度、剩余额度与建议等待时间；等待不代表操作已经执行，不应盲目重放玩家输入。
玩家命令可通过接管下的原生聊天，或不占用键鼠的当前玩家原生命令接口提交；两者仍受真实服务器权限限制。
Agent可以发现当前原生命令树和本地补全，也可显式请求有界服务器补全；补全与真人请求隔离，但服务器预算仍共享。还可以分批提交最多32条命令，逐项回执不是执行成功或原子事务。
原生聊天提交后的短窗口反馈只按时间关联，不保证属于该命令，也不代表服务器已确认成功。
原有聊天历史与隐藏内容不进入反馈，Agent仍应独立检查期望的玩家或世界状态。
界面调试读取会说明目标实际支持的修改、值单位与副作用；这些信息不向普通用户读取公开，也不自动授予调试权限。
世界调试遇到旧资源版本时，完整授权后可得到当前计数及重新读取提示；不能直接把计数当作新令牌或自动重试。
页面等待可以同时检查当前界面、加载覆盖层与可操作控件；区块读取等待区分未知、未加载和已知空气，不强制加载。
没有打开界面时，也可以等待无遮挡且窗口有效的游戏上下文；失败会说明加载覆盖层、界面或控件的哪部分尚未就绪，不推测隐藏内容。
接管后在后台首次进入世界也支持原生转向，宿主光标不被捕获；游戏没有请求逻辑捕获时会明确拒绝相对输入，不虚报已转向。
1.20.1与1.21.1的游戏模式菜单由原版下一帧提交选择；接管操作等待这次原生提交，取消不会留下迟到命令，菜单关闭本身不代表服务器已经切换模式。
自身玩家读取提供客户端已知的游戏模式、着地与正在飞行状态；不可得明确标记未知。
也可以读取自己的姿态、游泳/滑翔、所处水或熔岩、空气上限、经验与当前视角，帮助区分真实状态变化和仅已派发输入；这些仍是客户端已知信息，不是服务器确认。
乘坐时还可区分载具类型与自己是否为原生控制者；骑上羊驼等不代表能够驾驶，控制仍由原版规则和接管授权决定。
Agent还可以显式订阅当前客户端每tick的自身位姿与速度，不占用玩家控制权；卡顿或暂停时不承诺固定墙钟速率。
有界区域读取按小节分页返回客户端已加载方块，明确未加载与剩余范围；不会加载区块或读取服务器内部数据。
切换世界、玩家或连接时，旧按住状态会被清理，旧区域续读和旧位姿证据失效；普通界面换页不视为换世界。
无法命中目标时，可以查看有界的实际命中位置、方块面或实体类型，但不会因此绕过原版遮挡和交互距离。

Agent可以读取当前实际绘制的生命、护甲、食物、氧气和坐骑生命图标。读取只说明图标组合，不提供比画面更精确的内部数值；隐藏、过期或不完整的图标样本明确不可用。
1.20.1 Forge 的 F3、动作栏、唱片提示和 Demo 倒计时从加载器实际绘制出口读取，不以未绘制的文字缓存代替画面内容。

独立授权的界面调试可设置创造物品栏、织布机、切石机和交易界面的本地卷轴位置；这不是玩家滚动，不会选择配方、执行交易或取得物品。
修改仍需要当前界面版本和有效调试授权，测试后应恢复；原版没有可滚动内容时不能强行产生滚动范围。

界面调试也可替换本地标题、副标题和动作栏的纯文字，不发送玩家命令或改变世界事实。
原生命期和颜色动画可能被重置；恢复文字不保证恢复旧格式或计时，调试结果不能当作正常玩家测试证据。

26.x中带有未知服务器自定义动作的对话框或文字链接会在发送前拒绝；普通命令链接仍遵循原版玩家权限和命令效果分类。拒绝不会把已编辑的本地草稿谎称自动恢复。
当前还不开放函数、调度、区域克隆、模板放置、战利品生成，以及来源不明的物品复制或修饰器命令；这些会明确拒绝，不隐式读取服务器配置来猜测效果。

在带有自动合成器的版本中，Agent 可以读取网格槽位的禁用状态，并通过正常界面点击启用或禁用空格；禁用不代表不能点击。

在独立授权的调试操控中，Agent 可以设置已加载方块的合法状态属性，例如原木轴向或台阶类型；它不是玩家放置操作。
修改需要当前世界及方块版本和调试授权，不读取或写入存档文件。原版邻居更新、可能的掉落与方块实体替换仍会发生，测试后需恢复场景。
同步修改不会为邻居传播自动加载未知区块；传播中若已发生部分修改，会返回实际结果并标记诊断证据，不能把错误当作回滚或盲目重试。

## 安装与连接

1. 安装与你的 Minecraft 和加载器匹配的最终产品 JAR，不同时安装旧版或单独安全库。
2. 当前产品已包含自身所需的补充依赖，Fabric API也已随包交付；不要另外补Netty库来绕过旧发行包缺陷。
3. 启动安全测试实例，通过本机 Runtime HTTP/WebSocket 或 MCP Companion 连接。
4. 使用实例生成的认证令牌，按需要授权 scope，不将令牌发到公共聊天或提交。

客户端和服务端均可单独安装；单人游戏安装在客户端即可使用其集成服。
只装客户端时，可连接未安装本模组的服务器，使用界面、真实玩家输入、画面采证及客户端已知世界读取。
远端服务器内部数据及强类型修改没有正式通道时明确不可用；玩家 OP 或客户端调试授权不会凭空建立通道。
只装服务端时，原版客户端也可加入；Agent 可连接服务器自己的 Runtime，使用已授权的控制台和适用世界诊断资源。
玩家相关诊断必须选择真实在线玩家；其他适用资源不要求玩家在线，不会创建代理玩家或自动加载区块。
服务端不会提供玩家屏幕、截图或键鼠接管，也不要求有玩家在线才启动 Runtime。
两端都装时，可将客户端玩家操作与已批准的服务器权威诊断联动；服务器所有者签发绑定当前连接的限时委托，逐次检查权限、资源版本与撤权，不信任客户端自报已授权。
安装要求不授予 scope、服务器 OP、Debug Arm 或玩家控制租约；固定 Alpha 的实际能力以其同批手册为准。

Runtime 会自动选用空闲且可供标准网页连接的本机端口；让 Companion 明确选择你的实例，而不是猜测其他游戏的端口。
同一实例重复启动会拒绝共享连接身份；游戏重启后需要明确重新连接，不自动恢复接管。
需要固定端口时仍可由实例所有者配置，占用或被标准网页禁止时会失败，不会连到已有游戏。服务端游戏端口和网页端口仍独立配置。

## 控制与安全

独立授权的调试操控可修改支持的原生文本编辑器、可编辑书本与告示牌草稿；它不是玩家键盘输入。
原版行宽与页长限制仍生效，草稿可能随关闭界面提交，测试后应先恢复。当前alpha批次是否包含新增编辑器，应以随包手册为准。

玩家命令接口的“已接受”只代表已提交，不代表服务器执行成功。
原生命令树将效果分为沟通、信息和状态修改；未知、间接未决和宿主管理请求会拒绝，不提升玩家权限。
命令辅助接口使用真实聊天输入；信息读取不因辅助接口本身污染证据，修改状态仍标记诊断污染，不能当作自然游玩验收。
它不会覆盖已经打开的界面或聊天草稿，也不会绕过原版聊天长度限制。中途取消可能留下未提交草稿，由调用方明确处理。
包含文本组件的正常命令不会因读取结束边界被误报为上下文不可用；损坏参数或未解析后缀仍会拒绝。
发送异常或取消后也不要直接重发，应先观察实际状态；这不会增加玩家或 Agent 的权限。
组合输入失败、超时或取消时，仍可查询已经提交的命令来源；记录尚未收齐时会明确标记。
这份部分记录不代表操作成功、服务器确认或效果回滚，诊断污染不会因操作结束而消失。
聊天和链接的命令共用发送前检查；修改状态会保留诊断来源，输入回执不是实际效果保证。
接管中保存命令方块或命令方块矿车也需独立命令授权；宿主管理、不可用或影响尚未确定的命令会被拒绝。
保存查询命令、清空命令仍是配置修改，证据标记为诊断污染；保存回执不能当作命令已经执行。
Jigsaw 最终方块配置也会检查并保留诊断来源；模板生成目前因效果未决而拒绝。
原版生成按钮可能先保存配置，因此失败不等于完全没有修改，先观察结果再决定下一步。
结构方块更新参数和检测大小会保留诊断来源；检测是正常玩家动作，不是额外开放服务器读取。
结构文件保存与模板加载目前在发送前拒绝，不会先修改参数再报错；这两项的完整能力仍未提供。
26.1.2/26.3 的 Test 方块与 Test Instance 管理请求目前不开放；Agent 提交会在发送前拒绝。
Test Instance 文本框的调试设值也会拒绝，避免自动发出管理查询；普通输入可能留下本地草稿，不代表已改变服务器状态。
其他管理型界面的完整效果分类尚未完成，不把能点击按钮当作已通过安全验收。
命令载荷中嵌入的命令也会检查，不能通过生成命令方块、矿车或物品绕过限制。
普通名称文本不当作命令；无法确认来源的数据复制会拒绝，而不是暗中读取服务器或存档。
这不代表所有间接命令和世界连锁效果均已支持，遇到拒绝不要改用坐标或其他输入路径绕过。

Agent 可以从附近客户端方块/实体发现短期目标，通过真实玩家转头瞄准，再短按攻击或使用。
已持有的正常移动可与语义瞄准交互衔接，仍须实际命中和原版距离许可；不会替玩家寻路或绕过遮挡。
它仍受距离、遮挡、当前物品和原版校验约束；目标变化后需重新读取，不自动走近、不隔墙交互。
同一区块其他位置的变化不再直接让未变化的方块目标过期；目标被替换、先改后恢复、区块卸载或历史预算耗尽时，仍须重新发现目标。
支持有时限的持续挖掘、物品蓄力与指定表面放置；发送输入或客户端预测不保证服务器接受，Agent 需要再观察确认。
取消会释放按键，不回滚游戏效果；弓等物品可能在松键时生效。完整世界操作仍未覆盖。

- READ 只观察；OPERATE 的 Fixture/Debug 仍需各自授权；TAKEOVER 才能代替玩家输入。
- 组合操作不会绕过单项权限；界面操作和条件读取仍需对应授权，缺少授权时不会先执行组合中的前序玩家输入。
- 真人按 Esc 立即结束 TAKEOVER，观察继续可用；重新接管前 Agent 必须再次得到你的明确同意。
- 退出接管会一并取消正在执行和等待的玩家输入；不会把队列交接引起的租约失效误报成另一项操作失败。已完成的操作及独立调试工作不因此被改写或取消。
- 接管中的宿主光标保持自由，GUI 使用游戏内部虚拟指针。
- 26.x接管期间，宿主鼠标进入游戏窗口仍保持默认箭头，不因按钮或滚动条变成手形/缩放箭头；退出接管后恢复原版样式规则。游戏内蓝色圆球不受影响。
- 虚拟指针为 #339CFF 蓝色发光圆球，移动使用弹簧自然回弹；点击前停稳，按下时缩至 70%、松开后恢复，拖拽不做越过。
- 顶部提示平滑淡入淡出，四周蓝边轻缓呼吸；只有视觉渐变，权限生效与退出接管不会等待动画。
- 连续切换模式时，提示从当前展开状态平滑续接；收缩中的长文字限制在弹窗内部，不向右溢出。
- 窗口标题保留游戏原文并附加当前 Agent 状态；接管时，原窗口图标的右下四分之一叠加蓝色像素圆球角标。结束接管恢复游戏图标，游戏自行更新标题或图标时也会保留其最新内容。
- 球心对应实际操作落点，保留小数位置，不因画面缩放取整偏移；窗口右侧、底部的有效小数位置也不会因换页或缩放截断。背包格子按原生点击区域居中，悬停、点击与拖拽使用一致坐标。
- 创造背包的每个格子也有唯一语义编号，Agent 可直接选择格子进行悬停、点击和拖拽，不必使用坐标绕过。
- 普通菜单换页保留圆球位置；从第一人称打开背包等游戏有效释放动作遵循原版归中与显示规则，关闭时隐藏。宿主鼠标移动不会覆盖虚拟光标。
- 界面打开和连续操作之间保留短暂观看时间，减少高速切换造成的闪烁；这不会延迟 Esc 撤销或输入释放。
- 控制边框、提示与虚拟指针只供你观看，不进入默认截图或录制画面。

通过接口退出游戏时，请求可能因游戏关闭而提前取消；这不等于游戏崩溃，也不保证操作没有发生。
自动化调用方应查看明确的关闭/取消状态，并确认自己的游戏已正常退出，不重复点击退出或重放其他输入。

世界列表中可以对尚未选中的存档条目使用语义双击；第一次点击的正常选中不会被误报为目标失效。
存档身份、条目位置或界面发生其他变化时仍会停止，不能把过期条目的坐标用于继续点击。

- Debug/Fixture 证据不等同正常 gameplay；旧验收记录不代表当前版本已通过你的画面验收。

## 原版界面操作

Agent 可以直接选择世界列表中的存档、填写文本、调整滑块、滚动隐藏条目，
并操作嵌套按钮、创造物品栏标签和配方书控件；实际鼠标与文字输入仍经过游戏的正常输入路径。
界面或目标在操作途中改变时会拒绝旧目标，不会改为点击旧坐标。
容器中其他格子的后台更新不会打断对稳定格子的操作；目标格子的物品种类/数量、菜单身份或鼠标所持物品种类/数量变化仍会拒绝。
主动固定整个菜单版本时仍按严格版本检查，不自动重试或覆盖变化。
操作排队期间界面或菜单已变时，原始版本条件会在执行开始再次检查；失败不发送新输入。
多步骤操作不是可回滚事务，已完成的步骤或游戏自身变化仍需另行观察。
连续浏览多个页面时，身份缓存回收不会整批作废当前控件；长期未使用的旧目标仍需重新读取。
可按语义选择/排序资源包，操作交易、附魔、织布机、切石机与信标，编辑书本及普通/悬挂告示牌。
多人游戏列表中的已保存服务器也可按语义选择；悬停后读取连接和上下排序图标，添加、编辑、删除仍走原版界面与确认。
可以读取并操作书本/聊天文字链接、聊天建议、列表滚动条和进度画布；进度节点只提供实际存在的悬停能力。
创造物品栏、织布机、切石机和交易界面的滚动轨道与滑块也可按语义拖动；
