# Modern UI 适配

可见 View 树在 Modern UI 所属线程采样，以不可变 FRAMEBUFFER 投影进入标准 UI 树。
文本取实际 Layout，裁剪取框架可见矩形，不从隐藏 View 读取标签。
现有正常输入经过逻辑按钮快照和框架队列消费确认；保留原生点击、拖拽、滚动、焦点和文本路径。
撤销时取消框架触摸状态、清空按住和未提交字符，不移动宿主光标。
外部框架接口保持预览；具体版本的输入、撤权与业务覆盖以实际验证为准。

## 验证

具名场景在Modern UI自身配置页执行导航、滑块、文本恢复、实际轴滚动、拖拽和活动拖拽退回READ。输入快照、按下/松开、跨线程消费及清理属于真实框架路径，不能用performClick代替。客户端入口只在对应运行端执行；独服不声明UI能力。真实IME、宿主指针形状和物理Esc仍待用户集中验收，不以自动字符/预编辑测试替代；也不宣称所有嵌入Modern UI的第三方界面已经自动适配。
