# create 适配包

create:parts为普通机械轴承父方块提供有界USER部件与瞄准点，实际使用仍经TAKEOVER/Lease、原生pick与玩家右键。不能直接调用assemble/disassemble，也没有自动驾驶或寻路。

create:machine是服务器owner的DEBUG读取：速度、过载、轴承运行/装配异常、运动结构标识与有界方块列表。客户端和服务器useItemOn只读计数区分到达与业务效果；计数增加本身不代表装配成功。移动结构的内部列表不是可执行USER目标。

## 验证

具名场景以命令明确准备电机、轴承与小型结构，随后只用正常输入触发装配，并独立读取真实运行状态、结构和角度。零玩家独服验证机器读取与未加载拒绝。不是全部Create机械功能或移动部件交互验收；后者保持预览。
