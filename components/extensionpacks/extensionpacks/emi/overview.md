# EMI 适配

扩展标准 UI 树的当前可见搜索框、分页按钮、侧栏物品与配方内容。
侧栏只返回当前可见页，排除遮挡区域；虚拟配方物品标记 ingredient，不伪装成容器 Slot。
实际配方、用途、收藏、拖拽和滚动由既有原生 UI/input 路径执行，不调用配方或物品服务冒充玩家。
具体业务闭环与版本覆盖以平台实测为准；不承诺未验证的第三方配方控件。

## 安装与启用

从 Mine Craft Protocol 的模组配置入口打开扩展包页面，由真人初次启用；状态说明跟随游戏语言。重启后才装载此适配，禁用扩展不会卸载 EMI 本身。
批准绑定完整包内容与所申请的权限；代码、清单或随包说明更新后，都需要重新批准并重启，不能沿用旧内容哈希的授权。

## 验证

具名场景正常搜索、切换并恢复收藏、进入真实配方页并读取可见材料。USER不读取隐藏配方区域，不从物品预览生成实际库存。输入仍需TAKEOVER/Lease；客户端专用包在独服不执行入口。测试说明不自动启动场景或授予输入权限。
