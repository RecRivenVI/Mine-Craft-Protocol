# ae2 适配包

可见终端条目、控件、滚动条和合成确认材料表进入标准UI树。只返回当前显示的网格/表格，区分普通Slot与网络存储条目；数量、可请求和可合成标记来自客户端已同步内容。点击、存取及合成数量/确认走TAKEOVER、Lease、虚拟指针和原生GUI回调，不直接提交合成或改存储。

ae2:machine在服务器owner提供已加载机器的DEBUG状态：网络在线、节点、存储单元及CPU概况。没有玩家的独服可以读取，不虚构终端或输入Lease；读取不启动合成、不加载区块。固定上游及Target以包清单为准。

## 验证

具名场景建立隔离网络和固定配方作为Arrange，然后正常插入单元、存取木头、请求木板合成并取回真实背包；原生机器状态用于独立诊断。不是全部AE2机器/配方功能验收；运动结构和未知版本不自动适配。对应包测试索引只查阅说明，不执行操作。
